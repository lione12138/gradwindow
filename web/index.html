Q&A

Questions about the data

Three quick answers about how to read the tracker. Read the full methodology and sources.

Are these dates official?

Verified records link to the official university source and show when the date was checked. Confirm the programme page before submitting.

What does an estimated date mean?

An estimate shifts the latest verified cycle by one calendar year. It is a planning reference only and is never treated as an official application window.

Can deadlines differ by programme?

Yes. Dates can differ by course, faculty, funding route, applicant category, or visa status. Always open the specific course page before applying.
